# Формат файла достижения S5 Achievements (`s5adv` 1.0.0)

Для панели и для ручной правки. Мод нужен только на сервере.

## Где лежат и как называются

- Папка на сервере: `config/s5adv/` (у живого сервера это `<папка сервера>/config/s5adv/`).
- Один файл — одно достижение. Кодировка UTF-8.
- id достижения: `s5:<путь к файлу без .json>`. `attempt.json` → `s5:attempt`, `rp/first_aid.json` → `s5:rp/first_aid`.
  Подпапки можно.
- Имя файла (и папок): только `a-z 0-9 _ - . /`, **без заглавных и кириллицы**. Остальные файлы пропускаются с ошибкой.
- `root.json` (`s5:root`) — корень вкладки «Департамент». Если его удалить, при следующей загрузке мод положит его заново.
- Встроенные достижения мод кладёт сам, каждое по одному разу: `root.json`, `attempt.json` (шутка `/sex`),
  `spinning.json` (кружение, выдаёт RP Medicine). Что уже клал — записано в `config/s5adv/.defaults` (служебный,
  не трогать). Удалённые `attempt`/`spinning` не возвращаются. Код выдаёт их по id: переименовывать нельзя,
  тексты и флажки менять можно.

## Применить изменения

Записать/удалить файлы и выполнить на сервере (консоль, RCON или ГМ с правами 2):

```
/s5adv reload
```

Перечитываются только достижения s5, всем игрокам онлайн дерево досылается сразу. Датапаки не перезагружаются
(обычный `/reload` тоже подхватит файлы, но он тяжёлый). Ответ команды: `[s5adv] Перечитано: N достижений, ошибок: M`
и по строке ` • <id>: <что не так>` на каждую ошибку (в RCON приходит этот же текст). То же пишется в лог сервера
с префиксом `[s5adv]`.

Если файл сломан (не JSON, неизвестный предмет и т. п.), а до этого был исправен — остаётся прежняя версия
(в ошибке: «оставлена прежняя версия»), у игроков ничего не пропадает. Новый сломанный файл просто не загружается.
Прежняя версия живёт в памяти до перезапуска: если сервер стартует со сломанным файлом, достижения нет, и отметки
игроков о нём пропадут при их сохранении. Поэтому панели лучше проверять JSON перед записью и смотреть ответ `reload`.
**Удалённый файл = удалённое достижение**; у игроков его отметка исчезнет при следующем сохранении.

## Содержимое

Ванильный формат advancement 1.20.1 плюс наш блок `"s5"`. Минимальный файл:

```json
{
  "display": {
    "icon": { "item": "minecraft:wither_rose" },
    "title": "Попытка засчитана",
    "description": "Ты пытался. Моё мнение о тебе погибло."
  },
  "s5": { "toast": true, "chat": false, "hidden": true }
}
```

### Поля

| Поле | Обязательно | Что это |
|---|---|---|
| `display.title` | да | Название. Строка (`"Текст"`) или текстовый компонент JSON (`{"text":"…","color":"gold"}`). Пишется готовым текстом, не ключом перевода (на клиенте мода нет). |
| `display.description` | да | Описание, так же: строка или компонент. |
| `display.icon.item` | да | id предмета: `minecraft:…` или предмет мода из сборки (он есть у игроков). |
| `display.icon.nbt` | нет | NBT иконки строкой SNBT, например `"{CustomModelData:1}"`. |
| `display.frame` | нет | Рамка: `task` (по умолчанию), `goal`, `challenge`. Влияет на вид значка, заголовок всплывашки и текст в чате. |
| `parent` | нет | id родителя **из s5** (`"s5:attempt"`) — от него рисуется линия в дереве. Нет поля или родитель не из s5 → родитель `s5:root`. Так всё всегда в одной вкладке. |
| `criteria`, `requirements` | нет | Ванильные условия (любой триггер 1.20.1), если достижение должно выдаваться само. Нет условий → достижение выдаётся только командой или модом (`minecraft:impossible`). |
| `rewards` | нет | Ванильные награды (`experience`, `loot`, `recipes`, `function`). |
| `s5.toast` | нет, `true` | Всплывашка в углу экрана — только тому, кто получил. |
| `s5.chat` | нет, `false` | Сообщение в общий чат всем: «<имя> получил достижение [Название]» (ванильная строка клиента). gamerule `announceAdvancements` не нужен. |
| `s5.hidden` | нет, `false` | Скрытое: не видно в дереве, пока не получено (и его потомки тоже). |

Мод сам выставляет `display.show_toast`/`announce_to_chat`/`hidden` из блока `s5` — эти ванильные поля в файле
можно не писать, они перезаписываются. `display.background` действует только у `root.json`
(по умолчанию `minecraft:textures/block/gray_concrete.png`; любая текстура из ванили или мода, путь с `textures/…png`).
Расположение в дереве мод считает сам (как ваниль), координат нет. Лишние поля верхнего уровня игнорируются —
панель может хранить своё, например `"_panel": {…}`.

### Корень `root.json`

```json
{
  "display": {
    "icon": { "item": "minecraft:writable_book" },
    "title": "Департамент",
    "description": "Достижения сервера «Департамент S5»",
    "background": "minecraft:textures/block/gray_concrete.png"
  },
  "criteria": { "start": { "trigger": "minecraft:tick" } },
  "s5": { "toast": false, "chat": false, "hidden": false }
}
```

Триггер `minecraft:tick` выдаёт корень каждому сразу при входе — иначе вкладку не видно. `parent` у корня
игнорируется.

## Команды

| Команда | Права | Что делает |
|---|---|---|
| `/s5adv reload` | 2 | перечитать `config/s5adv`, дослать игрокам |
| `/s5adv list [игрок]` | 2 | все загруженные: id — название [флажки]; с игроком — ✔/✘ у кого есть |
| `/s5adv give <игроки> <id>` | 2 | выдать (`spinning` или `s5:spinning`; `@a` можно) |
| `/s5adv revoke <игроки> <id>` | 2 | отозвать |

Ванильные `/advancement grant|revoke <игрок> only s5:<id>` тоже работают.

## Для других модов (API)

```java
faygolover.s5adv.S5Advancements.grant(ServerPlayer player, String id);   // true — выдано сейчас
faygolover.s5adv.S5Advancements.revoke(ServerPlayer player, String id);
faygolover.s5adv.S5Advancements.has(ServerPlayer player, String id);
```

id — `"spinning"` или `"s5:spinning"`. Серверный поток. Нет такого достижения → `false`, без исключений.

## Встроенные id

| id | Кто выдаёт | Флажки |
|---|---|---|
| `s5:root` | все при входе (tick) | — |
| `s5:attempt` | шутка `/sex anasvaldigor` (первый ввод) | всплывашка, скрытое |
| `s5:spinning` | RP Medicine за кружение (через API) | всплывашка, скрытое |
